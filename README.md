## Movie-Rating
This awesome app specializes in providing numerical values of rotten tomatoes, IMBD,  and MetaScore. It will also provide movie details, such as the year, genre, director, etc. And a straight-forward, easy-to-read AI summery of the movie at the very bottom of the app. 


## Tools used to develop the app:
  * html
  * css
  * js
  * node.js
  * env
## Challenges that were overcame:
  * Integrating AI Using Groq's API
  * Integrating IMBD API
