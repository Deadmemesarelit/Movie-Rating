## Movie-Rating
This awesome app specializes in providing numerical values of rotten tomatoes, IMBD,  and MetaScore. It will also provide movie details, such as the year, genre, director, etc. And a straight-forward, easy-to-read AI summary of the movie at the very bottom of the app. 


## 🛠️ Tools Used
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Backend:** Node.js, Express
* **Environment:** dotenv (.env) for API key security
* **APIs:** Groq Cloud API (AI summaries), OMDb API (Movie data)

## 🚀 Challenges conquered
* **AI Integration:** Implementing Groq's API to generate concise, relevant movie summaries in real-time.
* **Data Aggregation:** Successfully fetching and parsing diverse rating formats from the IMDb/OMDb data structures.
* **Responsive Design:** Ensuring a seamless experience across desktop and mobile devices.
